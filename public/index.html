Отчёт КХЛ по интернет-аудитории

Данные из Яндекс.Метрики (API или CSV-выгрузки), текст — Claude. Результат в .docx.

Для каждого раздела приложите два файла — текущий и прошлый сезон (диапазон дат в имени файла определит, какой из них текущий).

Листы «Реализованные билеты», «Доход…», «Агенты…». В результат добавится лист «Расчеты» с метриками.

Если пусто — возьмётся максимальная посещаемость за матч.

По одному файлу на клуб. Общий отчёт: 4 параметра, по каждому — среднее/мин/макс по Лиге и места клубов (1..22) с градацией.

Лист «Чек-лист мониторинг»: история по сезонам, среднее/мин/макс и место по Лиге. После загрузки выберите клуб.

Один общий файл со всеми клубами (создаётся на вкладке «Агрегат по клубам», формат xlsx). Даёт значения текущего сезона — доля онлайн, средняя цена, доля бесплатных и агентская комиссия — по выбранному клубу, если в мониторинге они ещё не заполнены.

Добавит место региона клуба среди регионов присутствия КХЛ по среднедушевым доходам населения.

Подставляется в заголовки. По умолчанию — по датам данных.

Без галочки — быстрый черновик: только заголовки и таблицы.
